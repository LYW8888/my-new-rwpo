# 出生地与排盘时间联动

## 本次行为

| 输入情况 | 处理方式 |
| --- | --- |
| 不填城市、使用民用时间 | 可以生成；默认中国历史民用时区，不作经度或均时差修正 |
| 选择已收录城市 | 同时带入时区、城市ID与城市中心近似经度；不自动启用真太阳时 |
| 已选城市后启用真太阳时 | 直接使用已有经度，不再出现第二个城市选择框 |
| 同一城市换名称写法 | 支持“杭州/杭州市”“台北/臺北市”等；保留该城市下已手动修正的经度和时区 |
| 更换为其他城市 | 更新对应时区与经度 |
| 改为未收录地点或清空城市 | 清除旧经度和城市ID；原自动时区回到默认，显式选择的时区保留 |
| 真太阳时下未匹配城市 | 展开并定位经度输入，允许手动填写；0和负经度有效 |
| 切回民用时间 | 不提交经度和城市ID；页面内保留该对象的手动修正，方便再次启用 |

宝宝与改名对象仍使用独立资料。预产期仍可填写未来日期，默认12:00为参考时刻；出生后须按实际资料重算。改名仍须先分析现名，修改城市、时间口径或经度后重新分析，再推荐新名字。

## 可核对的结果

结果摘要明确显示民用时间或真太阳时。真太阳时展示原始时间、修正时间、提前/延后分钟数、经度、城市中心或手动来源，以及发生变化的柱；完整排盘继续提供经度项、均时差、历史时区与民用四柱。下载和账号主动保存的报告保留相同依据。

前后端均使用同一份20城市数据，仅接受明确名称匹配，不将城市名的任意子串识别为出生地。未知地址不会调用外部定位服务或猜测经度；城市中心是近似坐标，允许按实际地点修正。显式城市ID与已识别城市冲突时，API拒绝计算，避免悄悄采用另一个地点。

本次没有改变旺衰、喜用或字形五行规则。地点经由时区和可选真太阳时影响日柱、时柱与起卦，继而使用既有分析与选字规则。
